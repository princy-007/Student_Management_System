# Student Management System

A full-stack Student Management System built using **Python, Flask, HTML, CSS, and JavaScript**. This application allows users to manage student records through a simple and user-friendly web interface.

## Features

- User Login
- Dashboard
- View Students
- Add Students
- Edit Student Details
- Delete Students
- Responsive User Interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
